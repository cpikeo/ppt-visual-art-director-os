# Design Craft（设计判断手册 · 不是规则清单）

> **Director Kernel：先决定观众应该看到什么，再决定页面长什么样；先删除不必要的，
> 再决定需要什么视觉表达。任何视觉选择都必须能解释它为什么服务当前内容。**

三层权责，同一事实只判一次：Craft（为什么这样判断）→ intelligence/system（如何转成
决策）→ guard/contract/代码（哪些客观错误必须阻断，**全部数字住这一层**）。
反工程化原则：能被固定阈值完全描述的判断是工程约束，住代码，不住这里。本卷没有
「必须/禁止」清单；起草顺序是先想这页要让人记住什么，再让信号检查有没有失手。

## 一、减法链（核心操作系统）

「高级感不足」默认先怀疑判断不足，而不是元素不足。唯一修法顺序：

> **删除 > 重组 > 排版 > 强化 > 装饰**（删 → 合 → 排 → 强 → 装）

这句能不能删？两块能不能并？层级能不能只靠字号与墨色拉开？都试过才轮到强化装饰。
能用空间关系解决的，不要用新元素解决。高级感来自**更少、更准确、更有秩序的决定**。

**「所有东西都设计得很明显」是最典型的失手**——常常是没有任何东西愿意安静下来。
说不出职责的色块/线条/对齐/图标都是噪音。看到症状（模板感 / Dashboard 感 / 卡片墙 /
组件堆叠 / 过度圆角阴影渐变 / 无意义图标线条 / 过度 3D 装饰留白 / 为高级而高级 /
为变化而变化 / AI 机械布局 / 每页同结构），先问「哪个判断缺席了」，再沿链从左修。
故意做出某项，只要在 `composition_grammar` 写清意图就成立（见 §七）。

## 二、五个导演级判断（审查坐标系 · 无分数 · 无权重）

发布前逐页问「在哪个判断上失手」。超过 2 项明显失手 → 回炉。

**Focus —— 一个主语，一个锚点**：3 秒内是否只有一个主角？离开 30 秒后读者能复述哪个
锚点？「大标题 + 三张同面积卡片 + 一个图表」同场时读者会跳过整页——主语之外的元素都要
能被降级，**降级幅度不够 = 没降级**。「最大」不等于「最该被看见」：先确认它真是主语。

**Composition —— 留白是承重结构**：负荷失衡是否被声明为有意？元素落在轴线上还是随手
居中？空白有名字才有价值（protect_focus / hold_emotion / create_authority /
separate_chapter）；说不出职责的大片空白是排版事故。**主动留白常常是最贵的设计**。
非对称允许，但要说出靠什么平衡。每页能点出四层：Primary Focus / Secondary /
Supporting / Negative Space；突破要能说出靠什么收回秩序。

**Reading —— 路径、对比、诚信**：视线顺序是否由尺度/明度/位置决定？「哪儿都能开始看」
等于没有叙事。强调来自对比还是堆砌？文字在它下面的像素上真的可读吗？成片品质大多来自
「少而准」：一处强调色、一套字阶、一根轴线；要戏剧性用尺度/裁切/留白/光影，不用贴纸。
**数据表达不许撒谎也不许藏**：双轴、非零基线、堆叠占比、口径不齐先是诚信问题；读者要
自己心算才能确认结论＝图画错了；估算与外推必须带标记（EST./E）。

**Expression —— 气质、材质、色彩人格**：页气质是否匹配内容语气？**高级感不是一种色板**
——降饱和/米色/黑白灰/莫兰迪都不自动等于高级；高级来自关系准确：每色有职责、色相族
克制、强调稀缺、对比可读。高饱和只担单一职责时可以是克制的；满页低饱和而职责不清照样
廉价。方向混搭一次只混一个维度；说不清混什么就退回单方向。

**Continuity —— 整套 deck 是一个作品**：节奏/母题一致性/至少一个可复述记忆点都在
deck 级才存在；单页全对、整体平庸很正常。节奏是阅读的换气，不是每页轮换花样的义务
（换了标签没换画面 = 空转；同信息家族本来就该长得像）。**统一与差异都是手段，正确才是
目的**：统一气质/审美水准/排印逻辑/层级/秩序/节奏；不强行统一每页布局/配色/图片比例/
标题位置。说不出理由的变化是空转，说不出理由的重复是复制。

**贯穿五判断的两条纪律**：修正是设计动作不是分数动作——一轮只修一个根因（本轮最大
error），不为「把 84 改成 90」调 5 个参数。审美标尺用来校准判断不是用来复制——参考
Apple Keynote / Pentagram / FT / Bloomberg / Kinfolk / IDEO 是学「为什么把那个数字放
那么大」「为什么敢留那么多白」；版式截图、色板、组件、字体组合一律不带走；照搬处若不
能在当前内容上重新论证，就不该出现。

## 三、信号与权衡（数字住代码，这里只留「看什么、怎么权衡」）

中列信号只在两种时候发声：**几何/内容事实**，或**作者自己声明了刻度**。引擎不替作者判
审美；阈值不在本卷（门槛 → `production-contract.md`，首轮值 → `design-system.md`）。

| 观察点 | 信号 | 怎么权衡 |
|---|---|---|
| 强调色职责 | accent 面积、色相族数、与主辅色色相距 | 一个 deck 只让强调色干一件事；要更多颜色先削面积 |
| 字阶预算 | 字号档位数、家族数、跨页漂移 | 少一档字阶通常更清楚；层级不够用位置与明度补 |
| 焦点/节奏/卡片 | focus 绑定与领先幅度；连续同密度页数；每页卡片数 | 权衡见 §二 与 §一 |
| 圆角/阴影/渐变 | 形状语言与构图语法是否一致 | 形状语言属于气质：一份稿里三种形状语言＝没人负责审美 |
| 图表性格 | 同类图跨页标签规格、坐标处理一致性 | 先诚实再好看；同指标全 deck 同口径优先 |
| 高亮与注释 | 是否指向具体点、可解释、无冗余图例 | 没有结论可指时不必高亮 |
| 图标系统 | 来源/线宽/风格是否同族 | 宁可不用，也不用两套 |
| 装饰面积 | 非信息元素面积占比 | 看它是否承担 asset_function 或说得出口的空间职责；都不承担就是税 |
| 动效 | 入场动画数量与是否服务叙事 | 内部汇报直接关；发布会才让动画承担逐条揭示 |
| 文本行长 | 每行字数与折行块形 | 取决于内容密度/字号/场合——先加宽盒、拆句或改层级，没有通用上限 |
| 对齐 | 主轴数、边缘安静度 | 非对称要说出靠什么平衡 |
| 资产身份 | 是否声明 asset_role/asset_function、来源版权交代 | 空场景声明 emotion 却无媒体承担＝许愿未兑现；插图当背景铺底压字＝角色说错 |

> 阈值会漂：底线只升不调，漂了改代码常量；品味校准走 `memory/design_dna.json`。
> 别把新数字抄进本文件当法律。

## 四、摄影与图像质量

先分清**建立空间**还是**表达对象**（asset_role），再回答「它证明这页哪句话」
（asset_function），最后才谈质感。定位错了，再高质感也只是错位；回答不出的图是装饰，该删。

出图前逐张自问：
- **光是一句话吗**：从哪来、什么性格、落在哪个面？均匀的光 = 塑料。
- **空间有空气吗**：空气透视与虚实分层？尺度真实吗？
- **材质是真吗**：近看能摸到孔隙/纹理/釉面/纤维？过锐化与 HDR 感是「假」在补偿的指纹。
- **负空间在呼吸吗**：图自己留了文字与视线余地，还是靠裁切救？
- **主体成立吗**：插图问轮廓/尺度/位置能否独立识别并与文字成构图关系；背景问有没有在
  不该有主角的地方制造主角、把空间层做成海报。
- **它在这个世界吗**：与封面/章节页同一种光、同一族材质？一张异世界的图毁掉整稿世界观。

廉价症状（命中即重出；负面清单已由 `asset_prompt.py` 闸门在代码拦截）：图库式居中主体、
四角重暗角、塑料反光、过饱和、过锐化边缘、均匀棚光、拼贴感主体、「好看但无关」的风景、
AI 素材感（对称英雄构图 + 数字喷枪渐变）。

## 五、Typography 判断（杂志级）

行高/字阶/混排间隙见 `design-system.md` §字号阶梯（唯一真源）。这里只留阶梯之外的光学
判断。层级靠字体/字号/字重/行高/字距/段距/标题长度/文本宽度/对齐/基线/留白/中西比例/
数字单位关系建立，不靠颜色/边框/阴影/卡片。

- **字距**：Latin caps meta 行 +0.4–1.2pt 呼吸；**CJK 不加字距**；正文不加。Display 级
  Latin 大标题微收，CJK 大标题不收。
- **字重**：全稿默认 regular；**粗体每页至多一处**，只给承载结论的那一个词；不够先动位置
  与留白——粗体滥用是「不敢做层级」的症状。
- **中西关系**：混排拆 run；Latin 光学对齐 CJK baseline；数字按角色选比例/等宽，全稿统一
  一种性格；表格排行用等宽数字、小数右对齐。
- **呼吸**：标题四周留光学余量；meta 行永远单行、盒宽 ≥1.5× 冗余——meta 换行或裁切，
  整页秩序立刻崩塌（物理事实，见契约）。
- **办公字体感检验**：换回默认宋/黑体若气质毫无损失，说明排版没有设计——承载气质的是
  字阶、字距、行距与墨色关系，不是字体名字。

## 六、案例库（症状 → 判断 → 修法 → 教训）

**案例 0 · 六套样本的正面蒸馏**：六套气质完全不同的 deck 版式纪律高度同构——章节页全幅
重置；数据页单强调（大数字必带参照系或推荐列唯一染色）；摄影只以全幅出血或带呼吸边框
矩形出现；眉标/分隔线/页码同位。**判断**：成片品质是跨风格通用的版式纪律，不是风格并集。
**迁移**：大数字自带参照系（孤立大数字是海报不是数据）；摄影二选一；对比页只染答案；
时间轴以时期命名。**教训**：学样本不学皮——拆判断，不拆色值与截图。

**案例 5 · 水墨气质的两种死法**：封面是世界本体水墨，收尾却出摄影感远山（器材级空气透视、
渐变霞光、对称构图）——图像模型默认分布是「数字喷枪 + 图库风景」，不把材质语言写死进
提示词它就选最廉价的。**修法**：`asset_prompt.py` 水墨闸门在选择水墨语言时自动注入工艺
纪律（单笔意笔触、干笔渐变、过半纸地留白、三到四墨阶）与反向清单。**教训**：审美决策
（用不用水墨）留给导演；「选择水墨却允许画得廉价」是执行质量事故，归工程——写进代码的
是失效模式，不是口味。

**案例 6 · 阅读器会沉默失败**：meta 行尾部字形缺失，PPTX XML 完整、PowerPoint 正常——
某阅读器在「字符间距 ∧ run 级透明度并存」时丢弃 run 尾部字形；60dpi 缩略图还把截断误读成
对比度不足，险些改错方向。**修法**：带字距的文本不用 run 级透明度（透明度按局部底预混进
实色）；meta 行 `wrap=False` + 盒宽冗余；目检裁决用 150dpi 裁切。**教训**：交付品质 =
设计判断 × 阅读器事实；后者住契约与 DNA。同场沉淀：`focus` 声明视线第一落点而非叙事主语；
accent 须与照片色簇保持彩度距离。

**短案例（同一类错误的四种面孔）**：

| 症状 | 判断 | 修法 | 教训 |
|---|---|---|---|
| 5 张同面积卡片，机器全绿但层级失手 | 不敢决定哪个结论最重要 | 主结论提到 64 独占上半幅，其余降为无容器纯文本，删描边底色 | 先有「这页只有一句话」，卡片才会自己消失 |
| 两页堆叠柱，一页 12 期占比一页 4 季度绝对值（`DATA_INTEGRITY_FAIL`） | 诚信问题不是样式问题 | 统一 basis，绝对值挪附录，两页 unit/period 同写 | 图表一致性首先发生在数据语义层 |
| 开场页一句话占 6%，像没做完 | 空档是主角：让它有名字并兑现 | 写明空的职责，文字落左上 1/3 交点，1px 细线拉开与来源区的光学关系 | 「看起来空」和「空得没道理」是两件事 |
| 3 条节奏提示 + 4 条风险提示，作者顺手改色/字阶/圆角，另一页被切断 | 留痕信号不要求被消掉 | 只修唯一 error 根因，其余留在 trace_summary | 「为了提示」改设计＝被刻度牵着走 |

## 七、什么时候可以不照办

- **场合先于品味**：内部周报 5 页不必有记忆锚点；发布会 deck 不该塞满表格。fast/advanced
  是预算，不是审美等级。
- **反例是有用的**：故意对齐失败制造张力、卡片连成数据墙、两页同密度做连续压迫——都成立，
  前提是在 `composition_grammar` / `page_intent` 写清意图。评审看「意图是否被几何兑现」，
  不是「是否遵守默认」。
- **代码不同意你时**：只有工程事实能阻断（溢出/越界/数据/资产/对比度底线）。设计判断与
  留痕信号冲突 → 在 `design_rationale` 留一句理由，比改到刻度以内更有价值。
