# Design Craft（设计判断手册 · 不是规则清单）

> **Director Kernel（全卷一句话）：**
> **先决定观众应该看到什么，再决定页面应该长什么样；先删除不必要的东西，再决定需要
> 什么视觉表达。任何视觉选择都必须能解释它为什么服务当前内容。**

设计判断不能被阈值穷尽。三层权责，同一事实只判一次：

| 层 | 负责什么 |
|---|---|
| **Design Craft**（本卷） | 为什么这样判断——判断问题 + 权衡方式 + 案例 |
| **design-intelligence / design-system** | 如何把判断转成设计决策——策略、字段、首轮值 |
| **guard / production-contract / 代码** | 哪些客观错误必须阻断——**全部数字与阈值住这一层** |

**反工程化原则**：任何设计判断若能被一个固定阈值完全描述，它就不是设计智能，而是工程约束
——住 `guard.py` / `primitives.py`，不住这里。本卷没有「必须/禁止」句式的清单，只有判断方式
与真实案例。新写规则前先问：这条能不能用代码判掉？能 → 去代码；不能 → 写在这里。
起草顺序：先想这页要让人记住什么，再让信号检查有没有失手——反过来（先满足数字再填内容）
产出的一定像模板。

## 一、减法链（核心操作系统）

任何「高级感不足」的问题，**默认先怀疑判断不足，而不是视觉元素不足**。
页面不够高级时第一反应是加东西——那几乎总是错的。唯一的修法顺序：

> **删除 > 重组 > 排版 > 强化 > 装饰**（短记：删 → 合 → 排 → 强 → 装）

先从左走一遍：这句能不能删？这两块能不能并成一块？层级能不能只靠字号与墨色拉开
（而不是再加一档字号）？都试过了，才轮到强化与装饰。能用空间关系解决的问题，
不要用新元素解决。高级感来自**更少、更准确、更有秩序的决定**。

**「所有东西都设计得很明显」是最典型的失手**——真正的失手常常是一页里没有任何东西
愿意安静下来。说不出职责的色块、线条、对齐与图标都是噪音，不是丰富；高级页面允许
一大片区域什么都不说。看到症状（模板感 / UI Dashboard 感 / 卡片墙 / 组件堆叠 /
过度圆角 / 过多阴影 / 过多渐变 / 无意义图标与线条 / 过度 3D / 过度装饰 / 过度留白 /
为高级而高级 / 为变化而变化 / AI 机械布局 / 每页同一结构），先问「哪个判断缺席了」，
再沿链从左修。故意做出其中某一项，只要在 `composition_grammar` 写清意图就成立（见 §七）。

## 二、五个导演级判断（审查坐标系 · 无分数 · 无权重）

发布前逐页过一遍，问「这页在哪个判断上失手」，而不是问「得几分」。
超过 2 项明显失手 → 这页回炉。（旧第九维「交付状态」——无遮挡、无裁切、来源可溯——
归 QA 代码判，不进目检。）

### Focus —— 一个主语，一个锚点

3 秒内是否只有一个主角？焦点在尺度/位置上是否压倒一切，还是「也很显眼但差一点」？
离开 30 秒后，读者能复述哪一个锚点（一句 statement、一个数字、一张图）？

- 同画面出现「大标题 + 三张同面积卡片 + 一个图表」时，读者不会自己排序，他会先跳过整页。
  主语之外的元素都要能被降级（更小、更淡、更远、更少）——**降级幅度不够 = 没降级**。
- 「最大」不等于「最该被看见」：先确认它真是这页的主语，再谈尺度。

### Composition —— 留白是承重结构

画面负荷是否失衡（左右墨量、上下气压）？失衡是否被声明为有意？元素落在轴线上
（中线 / 三分 / 1⁄4 / 黄金分割），还是随手居中？

- 空白有名字才有价值（`protect_focus` 把人按在结论上 / `hold_emotion` 让气氛继续 /
  `create_authority` 建立权威 / `separate_chapter` 换脑）；说不出职责的大片空白是排版事故。
- **主动留白常常是最贵的设计**：一个大空档加一句短话，比铺满 12 条要点更贵。
- 非对称是允许的美（声明一下构图语法），但要能说出它靠什么平衡。
- 每页必须能点出四层：Primary Focus / Secondary Information / Supporting Detail /
  Negative Space。允许偏置、编辑式构图、强弱比例、尺度突变与局部突破，
  但底线是稳定、清晰、可读、平衡——突破要能说出靠什么收回秩序。

### Reading —— 路径、对比、诚信

视线顺序（标题 → 数字 → 结论 → 来源）是否由尺度、明度与位置决定？页面「哪儿都能开始看」
等于没有叙事；路径可以在一处故意打断，但要是有意的。强调来自对比还是堆砌？
文字在它下面的像素上真的可读吗？

- 成片品质绝大多数时候来自「少而准」：一处强调色承担全部重点、一套字阶承担全部层级、
  一根轴线承担全部对齐。加东西解决不了「不够好」，减东西经常能。
  要戏剧性时用尺度、裁切、留白、光影，不要用贴纸。
- **数据表达不许撒谎，也不许藏起来**：双轴、非零基线、堆叠占比、单位与期间口径、
  合计与分项不一致——先是诚信问题，其次才是美观问题。图的作用是让结论自证：
  读者要自己心算才能确认结论，说明图画错了。估算与外推必须带标记（EST./E）。

### Expression —— 气质、材质、色彩人格

页气质是否匹配内容语气（发布 / 危机 / 复盘）？色调、材质、光线在服务情绪，还是在表演风格？

- **高级感不是一种色板**：降饱和、米色、黑白灰、莫兰迪都不会自动等于高级——它们只是
  众多色彩人格之一。高级感来自关系准确：每个颜色都有职责（层级/情绪/品牌）、色相族克制、
  强调稀缺、对比可读。高饱和只承担单一职责时可以是克制的；满页低饱和而职责不清，照样廉价。
  选饱和人格先问内容的情绪温度与行业语境，不要问「高级长什么样」。
- **方向混搭一次只混一个维度**：借排版人格，或借留白纪律——说不清混的是什么，
  就退回单方向。
- 图像与摄影的判断问题见 §四。

### Continuity —— 整套 deck 是一个作品

节奏、母题一致性（同一强调色职责、同一图表性格、同一来源区位置）、至少一个可复述的
记忆点，都在 deck 级才存在。单页全对、整体平庸很正常。

- 节奏是阅读的换气，不是每页轮换花样的义务：相邻页疏密要有**事实变化**，
  换了标签没换画面 = 空转；同一信息家族本来就该长得像。
- 整套 deck 是一条叙事弧：Opening → Establish → Develop → Contrast → Deepen →
  Peak → Resolve；密度语气允许 Quiet / Editorial / Dense / Dramatic / Analytical /
  Spacious 混用。**避免每一页都"很设计"**——有变化但不失秩序才是高级。
- **统一与差异都是手段，正确才是目的**：不追求「每页都一样」（模板感），也不追求
  「每页都不一样」（拼盘感）。统一的是整体气质、审美水准、字体排印逻辑、信息层级、
  视觉秩序与叙事节奏；不强行统一的是每页布局、配色、图片比例、标题位置、网格与装饰。
  重复为了连续与扫读，变化为了换气与强调——说不出理由的变化是空转，说不出理由的重复是复制。

### 贯穿五判断的两条纪律

- **修正是设计动作，不是分数动作**：一轮只修一个根因（本轮 error 里最大那个），修完看一眼
  证据。不要为了「把 84 改成 90」去调 5 个参数——那会把已经对的地方改坏。
- **审美标尺用来校准判断，不是用来复制**：Apple Keynote / Pentagram / Swiss Typography /
  FT / Bloomberg / Kinfolk / Monocle / Wallpaper* / IDEO 的价值在于能说出它们「为什么把那个
  数字放到那么大」「为什么敢留那么多白」，然后把这套判断方式用回当前内容。版式截图、色板、
  组件、字体组合一律不带走。判据：把参考页的任何一处照搬过来，若无法在当前内容上重新论证
  一遍，它就不该出现。

## 三、信号与权衡（数字一律住代码，这里只留「看什么、怎么权衡」）

中列是代码顺手测出的信号（`guard.checks` 里以 advisory 出现）。**具体阈值不在本卷**：
门槛表见 `production-contract.md`，约束键与首轮值见 `design-system.md`，常量住 `guard.py` /
`primitives.py`。这些行只描述现象，不判对错。

| 观察点 | 代码顺手测的信号 | 怎么权衡 |
|---|---|---|
| 强调色的职责 | accent 实测面积、色相族数、与主辅色的色相距离 | 一个 deck 只让强调色干一件事（指向结论/关键数字）。要更多颜色就先削面积 |
| 字阶预算 | 字号档位数、家族数、同角色跨页字号漂移 | 少一档字阶通常更清楚。层级不够用位置与明度补，不要用更多字号补 |
| 焦点 / 节奏 / 卡片 | focus 绑定与领先幅度；连续同密度页数、相邻页墨迹差；每页卡片数 | 权衡已写在 §二（Focus / Continuity）与 §一（卡片墙症状），此处只是信号索引 |
| 圆角/阴影/渐变 | 形状语言与页面构图语法是否一致；渐变是否只用于体积 | 形状语言属于气质：一份年报里出现胶囊 + 硬边 + 描边三种，就没人负责统一审美 |
| 图表性格 | 同类图跨页标签规格、坐标处理方式是否一致 | 图表先诚实再好看；同一指标全 deck 同口径优先于让某一页更好看 |
| 高亮与注释 | 高亮是否指向具体点、是否可解释、有无冗余图例 | 没有结论可指时不必高亮；「好看的数据图」不等于「有观点的数据图」 |
| 图标系统 | 来源/线宽/风格是否同族 | 宁可不用图标，也不用两套图标 |
| 装饰面积 | 非信息元素面积占比 | 装饰值不值，看它是否承担 `asset_function` / `empty_space_role` 之一；都不承担就是税 |
| 动效 | 入场动画数量与是否服务叙事 | 内部汇报直接关掉；发布会场合让动画承担「逐条揭示」再开 |
| 文本行长 | 每行字数与声明换行的溢出倍数 | 行长失控先加宽盒或拆句；「一行 42 字」是不是问题，取决于内容密度与场合 |
| 对齐 | 主轴数、画面边缘安静度 | 非对称要能说出它靠什么平衡 |
| 资产身份 | 图片是否声明 `asset_function`、来源与版权是否交代 | 空场景声明了 emotion 却没有媒体承担，等于许了个没兑现的愿 |

> 阈值会漂：底线只升不调，漂了就改代码里的常量；品味校准走 `memory/design_dna.json`
> 经验条目。**别把新数字抄进这份文件当法律**——这里只留「看什么、怎么权衡」。

## 四、摄影与图像质量

> 图先回答「它证明这页的哪一句话」（`asset_function`），再谈质感。回答不出的图是装饰，
> 质感再高也该删。

出图前逐张自问（判断问题，不是清单勾选）：

- **光是一句话吗**：光从哪来、什么性格（窗光/漫射/侧逆）、落在哪个面上？均匀的光 = 塑料。
- **空间有空气吗**：前景与背景之间有空气透视与虚实分层吗？尺度真实吗（人的尺度、物的尺度，还是失尺度特写）？
- **材质是真吗**：近看能摸到孔隙、纹理、釉面、纤维吗？过度锐化与 HDR 感是「假」在补偿的指纹。
- **负空间在呼吸吗**：图自己留了文字与视线的余地，还是要靠裁切救？
- **它在这个世界吗**：与封面/章节页同一种光、同一族材质吗？一张异世界的图毁掉整稿世界观。

廉价症状（命中即重出；出图层负面清单已由 `asset_prompt.py` 的摄影/水墨闸门在代码里拦截）：
图库式居中主体、四角重暗角、塑料反光、过饱和、过锐化边缘、均匀棚光、拼贴感主体、
「好看但无关」的风景、AI 素材感（对称英雄构图 + 数字喷枪渐变）。

## 五、Typography 判断（杂志级）

行高、字阶区间与中西混排间隙见 `design-system.md` §字号阶梯（唯一真源，别在这里另立一套）。
这里只留阶梯之外的光学判断。控制面：字体、字号层级、字重、行高、字距、段落间距、
标题长度、文本宽度、对齐关系、基线关系、留白关系、中西比例、数字与单位关系——
层级靠这些建立，不靠颜色/边框/阴影/卡片。

- **字距**：Latin caps 的 meta 行（眉标/章标/落款）给 +0.4–1.2pt 撑开呼吸；**CJK 不加字距**
  （全角字面自带均匀节奏）；正文不加字距。Display 级 Latin 大标题微收（-1%–-2%），CJK 大标题不收。
- **字重**：全稿默认 regular；**粗体每页至多一处**，且只给承载结论的那一个词。字重不够先动位置与留白
  ——粗体滥用是「不敢做层级」的另一种症状。
- **中西关系**：混排拆 run（CJK/Latin 各用其字体），Latin 光学对齐 CJK baseline；
  数字按角色选比例/等宽，全稿统一一种性格；表格与排行用等宽数字、小数右对齐。
- **呼吸**：标题四周留光学余量（不顶轴、不贴图边）；meta 行永远单行、盒宽留 ≥1.5× 冗余
  ——meta 行换行或裁切，整页秩序立刻崩塌（物理事实，见契约「可读性与裁切」）。
- **办公字体感检验**：把字体换回默认宋/黑体，页面气质若毫无损失，说明排版没有设计
  ——承载气质的是字阶、字距、行距与墨色关系，不是字体名字。

## 六、案例库（真实往返：症状 → 判断 → 修法 → 教训）

> 入库 house style：加粗只给行首标签，段内不用行内加粗——行内加粗会扰乱部分阅读器对软换行 CJK
> 段落的强调解析，整段变粗（案例 6 曾因此与全库格式分裂）。段内强调一律「」或 inline code。

### 案例 0 · 六套样本的正面蒸馏

**可观察行为**：六套气质完全不同的 deck（极简产品 × 网格 / 东方编辑 / 财经战略 / 奢侈品牌 /
未来 AI / 博物馆档案），版式纪律却高度同构——章节页全部全幅重置（大编号或满幅图 + 单 statement）；
数据页全部单强调（大数字必带参照系，或被推荐列唯一染色）；摄影只以两种形态出现（全幅出血，
或带呼吸边框的矩形），从不半吊子贴边；眉标 caps、细分隔线、页码象限全部同位。
**判断**：成片品质不是六套风格的并集，而是跨风格通用的版式纪律——风格是人格的事，纪律是判断的事。
**迁移手法**：大数字必须自带参照系（+62% 永远跟「vs. Q4」；孤立大数字是海报不是数据）；
摄影二选一（情绪/章节页全幅出血，证据/语境页带呼吸边框矩形；半幅贴边是图库感的来源）；
对比页只染答案一格/一列；时间轴以时期命名，不用年份罗列。
**教训**：学样本不学皮——拆出的应是判断（何时全幅、染色染哪里、参照系带什么），不是色值与版式截图。

### 案例 5 · 水墨气质的两种死法

**症状**：封面是世界本体的水墨远山；收尾页却出了一张摄影感远山——器材级空气透视、渐变霞光、
对称构图，与封面不在同一世界，负面清单「商业图库感」当场应验。
**判断**：这不是「生图运气不好」。东方/水墨题材上，图像模型的默认分布是「数字喷枪渐变 + 图库风景摄影」；
不把材质语言写死进提示词，它就替你选最廉价的那种。廉价水墨的症状可枚举：摄影化山体剪影、
泥污状灰墨淤积、随机泼溅、过饱和红日/圆盘、竹/鹤/锦鲤剪贴画感、画面中心对称、四角重暗角。
**修法**：不写成人的背诵清单——`asset_prompt.py` 的水墨纪律闸门在资产卡选择水墨语言时自动注入
工艺纪律（单笔意笔触、干笔渐变、过半纸地留白、三到四个墨阶）与反向清单；家族名本身即点火。重生成一次通过。
**教训**：审美决策（用不用水墨）永远留给导演；「选择了水墨却允许画得廉价」是执行质量事故，归工程管。
写进代码的是失效模式，不是口味。

### 案例 6 · 阅读器会沉默失败

**症状**：目检发现 meta 行（眉标/章标/页码/封面英文标/落款）尾部字形缺失；PPTX XML 文本完整、
PowerPoint 显示正常——只有部分阅读器的预览/导出受害。
**判断**：先怀疑自己的几何（盒宽/换行），用最小探针矩阵（字距/透明/行距/对齐逐项开关）证伪：
真因是「字符间距 ∧ run 级透明度并存」时该阅读器丢弃 run 尾部字形（advance 保留、字形不画）
——渲染器沉默缺陷，与设计无关；60dpi 缩略图还会把「截断」误读成「对比度不足」，险些改错方向。
**修法**：带字距的文本不用 run 级透明度——透明度按局部底预混进实色，或直接用实墨；
meta 行统一 `wrap=False` + 盒宽冗余；目检裁决用 150dpi 裁切。
**证据**：裁切目检全完整；release PASS；沉淀 DNA `lo_spc_alpha_glyph_drop`。
**教训**：同场另两条工程事实一并入契约/DNA：`focus` 要声明「视线第一落点」（英雄图/索引场/主数字），
而非叙事主语——重力只认眼睛真正落的地方；accent 须与照片色簇保持彩度距离
（暖铜/赭血乃至灰蓝在土色照片簇内全部同族阵亡，仅足彩度钴蓝存活）。
交付品质 = 设计判断 × 阅读器事实；后者住契约与 DNA，不住品味。

### 短案例（1–4：同一类错误的四种面孔）

| 症状 | 判断 | 修法 | 教训 |
|---|---|---|---|
| 一页 5 张同面积卡片 + 小标题，机器全绿但层级明显失手 | 问题不在「卡片太多」，在于不敢决定哪个结论最重要 | 把「留存率 -6.4pt」提到 64px 独占上半幅，其余四条降为无容器纯文本 + 18px，删掉卡片描边与底色 | 先有「这页只有一句话」的判断，卡片才会自己消失 |
| 两页都用堆叠柱，一页按 12 期做占比、一页按 4 季度做绝对值，读者以为在比同一件事（`DATA_INTEGRITY_FAIL`） | 这是诚信问题，不是样式问题 | 统一 `basis`，绝对值挪到附录页，两页 `unit/period` 同写 | 图表一致性首先发生在数据语义层 |
| 开场页只有一句话，占画面 6%，看起来像没做完 | 这里空档是主角：让空档有名字并兑现它 | `empty_space_role` 声明职责、文字落左上 1/3 交点，加一条 1px 细线把句子与来源区拉开光学关系 | 「看起来空」和「空得没道理」是两件事，后者才要修 |
| 报告有 3 条节奏提示 + 4 条风险提示，作者顺手改了色/字阶/圆角，复跑后另一页文字被切断 | 修订理由不能是「提示太多」；advisory 本来就不要求被消掉 | 只修唯一 error 的根因（那页溢出），其余提示留在 `trace_summary` | 如果某轮你是「为了提示」改设计，说明在被刻度牵着走——该改的是证据，不是口味 |

## 七、什么时候可以不照办

- **场合先于品味**：内部数据周报的 5 页 deck 不必有「记忆锚点」；发布会 deck 不该塞满表格。
  `fast / advanced` 是预算，不是审美等级。
- **反例是有用的**：故意对齐失败制造张力、故意让卡片连成一块做「数据墙」、故意让两页同密度做
  连续压迫感——都成立，前提是你在 `composition_grammar` / `page_intent` 里写清意图。
  评审看的是「意图是否被几何兑现」（`design_rationale`），不是「是否遵守了默认」。
- **代码不同意你时**：只有工程事实能阻断你（溢出、越界、数据、资产、对比度底线）。
  设计 advisory 与你的判断冲突 → 在 `design_rationale` 里留一句理由，比改到刻度以内更有价值。
