# Design Craft（设计判断手册 · 不是规则清单）

## 判断基线（v4.15：审查模式的原班九维——从代码引擎提炼为约束叙事）

> 原 art_critic 模块的 9 维评分系统已从整体移除（代码不再替你打分）；
> 但它的**评审坐标系**保留为审查模式下的判断基线——九维没有消失，
> 消失的是「维度可以被代码替你打分」这个幻觉。现场用法：发布前逐页对照，
> 自问这页在哪个维度失手，而不是问机器「我的分多少」。

| 维度 | 评审会问什么（权重仅为提示：先问前两个） | 常见失手 |
|---|---|---|
| visual_hierarchy (20) | 3 秒内是否只有一个主角；焦点元素在尺度/位置上是否压倒一切 | 焦点不领先（<1.25×）；同级互抢 |
| balance (15) | 画面负荷是否失衡（左右墨量、上下气压） | >45% 左右失衡未声明非对称 |
| alignment (10) | 是否落在轴线（中线/三分线/1⁄4/黄金分割）之上 | 完全不上线、随手居中 |
| contrast (10) | 强调是否源于对比而非堆砌？文字是否在它下面像素上可读 | 深底深字；低对比正文 |
| rhythm (10) | 相邻页是否该呼吸（疏密交替、节奏有事实变而非标签变） | DENSITY_FLAT；交替空转 |
| consistency (10) | 字体/色/间距是否严守 token；全稿是否源自同一套系统 | 组件各写各的、模板混装 |
| emotional_impact (10) | 页气质是否匹配内容语气（发布/危机/复盘）；色调是否服务情绪 | 危机页亮蓝底；复盘页全暖红 |
| memorability (10) | 离开 30 秒后读者能复述哪一个锚点 | 没有 statement 尺度；无锚 |
| professional_quality (5) | 交付状态：无遮挡/无裁切/来源可溯——但这是 QA 的职责 | （工程判定已在 guard/QA） |

超过 2 项明显失手 → 该页回炉重生成（revise 语义）；左两列权重（visual_hierarchy/balance）权重只是评审看先后的提示，**真实世界先问焦点再问负荷**。分数不是目标——判断是。

---

> 这份文件的存在理由：**设计判断不能被阈值穷尽**。`guard.py` 与 `primitives.py` 里的数字
> 是**参考刻度**——它们告诉你「评审会往哪儿看、看到什么算异常」，不告诉你「照做就高级」。
> 起草时的正确顺序是：先想这页要让人记住什么，再用刻度检查有没有失手；反过来（先满足
> 数字再填内容）产出的东西一定像模板。
>
> **反工程化原则（全技能包通用）**：任何设计判断若能被一个固定阈值完全描述，它就不是
> 设计智能，而是工程约束——那种东西应该住在 `guard.py` 或 `primitives.py` 里，而不是变成
> 一条需要你背诵的法律。所以这份文件里**没有「必须/禁止」句式的清单**，只有判断方式、
> 刻度位置、以及真实案例。新写规则前请先问：这条能不能用代码判掉？能 → 去代码；不能 → 写在这里。

## 一、七条判断原则（代码判不了、但一眼看得出好坏）

1. **页面只有一个主语。** 一画面上同时有「大标题 + 三个同面积卡片 + 一个图表」时，读者
   不会自己排序，他会先跳过整页。主语之外的元素都要能被降级（更小、更淡、更远、更少），
   而不是「也很显眼但差一点」。降级幅度不够 = 没降级。
2. **留白是承重结构，不是剩余物。** 空白有名字才有价值：`hold_attention`（把人按在结论上）/
   `hold_emotion`（让气氛继续）/ `create_breath`（换气）/ `frame_focus`（把焦点托起来）。
   说不出职责的大片空白就是排版事故。反过来，**主动留白常常是最贵的设计**——一个占 30% 画面
   的空档 + 一句 44px 的话，比铺满 12 条要点更贵。
3. **先决定观众要走的路径，再摆放。** 视线顺序（标题 → 数字 → 结论 → 来源）应该由元素
   尺度、明度与位置决定；如果你的页面「哪儿都能开始看」，等于没有叙事。路径可以在一处
   故意打断（反高潮、留悬念），但要是有意的。
4. **对比优先于装饰，克制优先于丰富。** 高级感绝大多数时候来自「少而准」：一处强调色
   承担全部重点、一套字阶承担全部层级、一根轴线承担全部对齐。加东西解决不了「不够好」，
   减东西经常能。真需要戏剧性时，用尺度、裁切、留白、光影，不要用贴纸。
5. **数据表达不许撒谎，也不许藏起来。** 双轴、非零基线、堆叠占比、单位与期间口径、
   合计与分项不一致——这些先是诚信问题，其次才是美观问题。图的作用是让结论自证：
   读者需要自己心算才能确认结论，说明图画错了。估算与外推必须带标记（EST./E），与实测区分——读者分不清估计与事实，就是撒谎的一种。
6. **整套 deck 是一个作品，不是 12 页拼盘。** 节奏（密—密—疏—爆）、母题一致性（同一
   强调色职责、同一图表性格、同一来源区位置）、以及至少一个可复述的记忆点，都在 deck 级
   才存在。单页全 A 的 deck 可以整体平庸，这很正常。
7. **修正是设计动作，不是分数动作。** 一轮只修一个根因（`director_verdict.primary_lever`），
   修完看一眼证据。不要为了把 84 分改成 90 分去调 5 个参数——那会把已经对的地方改坏。

## 二、参考刻度（观察点 → 数值信号 → 怎么权衡）

这些行**只描述现象**，不判对错。左列是你该看的东西，中列是代码顺手测出的信号（在
`guard.checks` 里以 `advisory` 标记出现，或 Critic 的 `dimension_evidence`），右列是取舍。

| 观察点 | 代码顺手测的信号（参考刻度） | 怎么权衡 |
|---|---|---|
| 强调色的职责 | Accent 实测面积（>5%/页起疑）、色相族数（>4 起疑）、与主辅色相差（<12° 会糊） | 一个 deck 只让强调色干一件事（指向结论/关键数字）。要更多颜色就先削面积 |
| 字阶预算 | 字号档位 5/6 起疑、家族 >2、同一角色跨页字号漂移 >1.25× | 少一档字阶通常更清楚。层级不够时用位置与明度补，不要用更多字号补 |
| 焦点的可见性 | `focus` 是否绑定元素、焦点字 ≥40px 或领先次高 1.25×、其他元素面积 ≤max(2×焦点, 25%) | 「最大」不等于「最该被看见」；先确认它确实是这页的主语，再谈尺度 |
| 版面节奏 | 连续 3 页同密度同能量（rhythm）、相邻页墨迹差 <0.10（换了标签没换画面 = 空转） | 节奏是为阅读服务的换气，不是每页轮换花样的义务；同一信息家族本来就该长得像 |
| 卡片与容器 | `rounded_rect` ≤4/页、卡片是否承载数据模块/指标/特殊强调 | 卡片墙是「不敢做层级」的症状。数据模块之间用留白与对齐分开，往往比描边体面 |
| 圆角 / 阴影 / 渐变 | `organic_layer`：形状语言与页面 `composition_grammar` 是否一致；渐变是否只用于体积 | 形状语言属于「气质」：一份年报里出现胶囊 + 硬边 + 描边三种，就没人负责统一审美 |
| 图表性格 | `chart_style_drift`：同类型图跨页标签规格、坐标处理方式是否一致 | 图表先诚实再好看；同一指标全 deck 同口径优先于让某一页更好看 |
| 高亮与注释 | `chart_highlight`：是否指向具体点、是否可解释、有无冗余图例 | 没有结论可指时不必高亮；「好看的数据图」不等于「有观点的数据图」 |
| 图标系统 | `icon_consistency`：来源/线宽/风格是否同族 | 宁可不用图标，也不用两套图标。图标承担语义时优先于装饰性 |
| 装饰面积 | `decoration_budget`：非信息元素面积占比（>10% 起疑） | 装饰值不值，看它是否承担 `asset_function`/`empty_space_role` 之一；都不承担就是税 |
| 动效 | `animation_budget`：入场动画数量与是否服务叙事 | 内部汇报可以直接关掉；发布会场合让动画承担「逐条揭示」的功能再开 |
| 文本行长 | `typography`：每行 CJK 约 38 字/拉丁 70 字符的建议区间（超 3× 会被切断 → 那才是 error） | 行长失控先加宽盒或拆句；但「一行 42 字」是不是问题，取决于内容密度与场合 |
| 对齐 | `alignment_budget`：主轴数（>4 起疑）、渲染 edge_kurtosis ≥4 为佳 | 非对称构图是允许的美（`composition_grammar` 声明一下），但要能说出它靠什么平衡 |
| 资产身份 | `asset_contract`：图片是否声明 `asset_function`、来源与版权是否交代 | 空场景声明了 `color_intent=emotion` 却没有媒体承担，等于许了个没兑现的愿 |
| 声明层一致性 | `background_layer`：整幅承载 + 遮罩 ≥0.20 + `content_protection` | 这一条是**例外**：伪装背景层/文字压在图上不可读会被阻断，因为那是物理事实不是口味 |

> 阈值会漂：底线只升不调，漂了就改代码里的常量；品味校准走 `memory/design_dna.json` 经验条目（见 `design-system.md` §Taste Calibration），不走阈值反推。
> **别把新数字抄进这份文件当法律**——这里只留「看什么、怎么权衡」。

## 三、案例库（真实往返：症状 → 判断 → 修法 → 证据）

### 案例 0 · 六套世界级样本的正面蒸馏（用户供稿：Apple×Swiss / 东方编辑 / FT 战略 / 奢侈品牌 / 未来 AI / 博物馆档案）
**可观察行为**：六套气质完全不同的 deck，版式纪律却高度同构——章节页全部全幅重置（大编号/全幅图 + 单
statement）；数据页全部单强调（大数字必带参照系，或被推荐列唯一染色）；摄影只以两种形态出现（全幅出血，
或带呼吸边框的矩形），从不半吊子贴边；眉标 caps、细分隔线、页码象限，六套全部同位。
**判断**：高级感不是六套风格的并集，而是这套跨风格通用的版式纪律——风格是人格矩阵的事，纪律是判断的事。
**迁移手法**：大数字必须自带参照系（+62% 永远跟「vs. Q4 2023」，孤立大数字是海报不是数据）；摄影二选一
（情绪/章节页全幅出血，证据/语境页带呼吸边框矩形，半幅贴边是图库感的来源）；对比页只染答案一格/一列；
时间轴以时期命名不用年份罗列。
**证据**：`memory/design_dna.json` 新增 `comparison_single_decision`、`timeline_named_eras` 两条可召回经验；
页型节奏三手法见 `design-intelligence.md` §Deck Rhythm。
**教训**：学样本不学皮——拆出的是判断（何时全幅、染色染哪里、参照系带什么），不是色值与版式截图。

### 案例 1 · 卡片墙不是层级，是回避
**症状**：产品复盘页 5 张同面积卡片 + 一行小标题。QA 全绿，Critic `visual_hierarchy 2.8`，
`focus` advisory 命中（焦点面积 22% vs 卡片 20%，差 1.1×）。
**判断**：问题不在「卡片太多」，在于作者不敢决定哪个结论最重要。
**修法**：把「留存率 -6.4pt」提到 64px 独占上半幅，其余四条降为无容器纯文本 + 18px，
删掉 4 张卡片的描边与底色（装饰预算从 17% 降到 3%）。
**证据**：`rhythm`/`type_budget` advisory 自然消失，`memorability` 从 3 → 4.5（记忆锚点从
「图表内部数字」变成 44px+ 的陈述级文本）。
**教训**：分数是副产品；先有「这一页只有一句话」的判断，卡片才会自己消失。

### 案例 2 · 同口径优先于同外观
**症状**：两页都用堆叠柱，第 4 页把「营收」按 12 期做占比，第 9 页按 4 季度做绝对值。
读者以为在比较同一件事。`chart_style_drift` advisory + `FACT_BASIS_MISMATCH` error。
**判断**：这是诚信问题，不是样式问题；把两页「做齐」不是让形状一致，而是让口径一致。
**修法**：两页统一 `basis: "share_of_period"`，绝对值改到附录页；两页 `unit/period` 同写。
**教训**：图表的一致性首先发生在数据语义层。改样式解决不了 `INVALID_DATA` 之外的东西。

### 案例 3 · 留白当预算，不当剩余
**症状**：投资人会议开场页只有一句「我们只留下能自己活下来的产品线」，占画面 6%。
`rhythm` 报 sparse，`decoration_budget` 报 0——看起来像没做完。
**判断**：这里空档是主角。要做的不是「补内容」，而是让空档有名字并兑现它：
`empty_space_role: hold_attention`、`protect_focus`、文字落在左上 1/3 交点。
**修法**：加一条 1px 的细分割线把句子与来源区拉开光学关系（不是装饰），其余保持不动。
**证据**：`alignment` 5.0（8 单位网格全中）、`memorability` 5.0（statement 44px）。
**教训**：「看起来空」和「空得没道理」是两件事；后者才要修。

### 案例 4 · 一次只修一个根因
**症状**：某轮 QA 97.7 分，报告里 3 条 rhythm hint + 4 条 preflight 提示，作者顺手改了
色彩、字阶、卡片圆角，重跑变 96.9，且第 4 页文字被切断。
**判断**：修订理由不能是「分数低了一点」。`advisory` 条目权重 0，本来就不要求被消掉。
**修法**：回到 `primary_lever`（该页 `text_capacity` 溢出），只加宽盒子 + 拆一句；
其余提示按 `batch.deferred` 排队。
**教训**：guard 的设计观察不扣分——如果某轮你「为了 QA 分数」改了设计，
说明你在被刻度牵着走，正确动作是改证据而不是改口味。

### 案例 5 · 水墨气质的两种死法（2026-annual-review 实战）
**症状**：封面是世界本体的水墨远山；收尾页却出了一张「好莱坞摄影感」的远山——
器材级的空气透视、渐变霞光、对称构图，负面清单「商业图库感」当场应验，且与封面不在同一世界。
**判断**：这不是「生图运气不好」。东方/水墨系题材上，图像模型的默认分布是
「数字喷枪渐变 + 图库风景摄影」；你不把材质语言写死进提示词，它就替你选最廉价的那种。
廉价水墨的可识别症状高度可枚举：摄影化山体剪影、泥污状灰墨淤积、随机泼溅、
过饱和红日/圆盘、皮拉竹/鹤/锦鲤的剪贴画感、画面中心对称、四角重暗角。
**修法**：不把它写成人的背诵清单——`asset_prompt.py` 的水墨纪律闸门在检测到
资产卡已选择水墨语言时，自动注入工艺纪律（单笔意筆觸、干笔渐变、过半纸地留白、
三到四个墨阶）与上述廉价症状的反向清单；`song_elegance / zen_minimal` 家族名
本身即点火。重生成一次通过。
**教训**：审美决策（用不用水墨）永远留给导演；但「选择了水墨却允许画得廉价」
是执行质量事故，归工程管。写进代码的是失效模式，不是口味。

## 四、什么时候可以不照办

- **场合先于品味**：内部数据周报的 5 页 deck 不必有「记忆锚点」；发布会 deck 不该塞满
  表格。`fast / advanced` 是预算，不是审美等级。
- **反例是有用的**：故意对齐失败（打破轴线）制造张力、故意让卡片连成一块做「数据墙」、
  故意让两页同密度做「连续压迫感」——都成立，前提是你能在 `composition_grammar` /
  `page_intent` 里写清意图。Critic 看的是「意图是否被几何兑现」（`design_rationale`），
  不是「是否遵守了默认」。
- **代码不同意你时**：只有工程事实能阻断你（溢出、越界、数据、资产、对比度底线）。
  设计 advisory 与你的判断冲突 → 在 `design_rationale` 里留一句理由，比改到刻度以内更有价值。

- 记忆：`memory/design_dna.json` 是**决策记忆**（这个场合这类内容当时怎么判断、后果如何），
  不是 500 条规则；`recall_dna(brief)` 命中即可当判断基线。
