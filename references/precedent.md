# Precedent（案例库与经验记忆 · DNA）

历史校准：案例库（症状 → 判断 → 修法 → 教训）与 Design DNA 的沉淀/召回用法。
判断方法 → `judgment.md`；字段 → `contract.md`。

## 1. Design DNA（判断记忆）

`memory/design_dna.json` 记录的是**为什么某个设计判断有效**，不是参数库：
每条 = `pattern`（模式名）+ `design_problem`（当时矛盾）+ `judgment`（可迁移的行为判断）
+ `works_because`（为什么成立）+ `avoid` + `when_not_to` + `proven`（实测证据）。

- **DNA 只记判断，不记坐标、固定颜色、固定布局、组件模板**——judgment 里出现色值/
  字号/版式结果会被拒收；结果属于证据，放 `proven.measurements`。
- **召回**：`plan` 在规划时自动按 brief 关键词打分召回（置信度 = 命中词占比）。
  DNA 是起点不是模板：低置信按当前内容与受众重组，禁止照抄。
- **沉淀**：release PASS 且案史空白时，链路给一句提示（不自动写——写坏的记忆比不写
  更贵，沉淀是判断动作，不是机制动作）：

```bash
python scripts/vao.py dna --add entry.json        # 校验 → 去重 → 原子写入
python scripts/vao.py dna --check                 # 体检：结构问题点名到条目
```

入库时机：这局的方向判断有效、且下一次遇到同类矛盾时你想被提醒「为什么」。

## 2. 案例库（症状 → 判断 → 修法 → 教训）

**案例 0 · 六套样本的正面蒸馏**：六套气质完全不同的 deck 版式纪律高度同构——章节页
全幅重置；数据页单强调（大数字必带参照系或推荐列唯一染色）；摄影只以全幅出血或带
呼吸边框矩形出现；眉标/分隔线/页码同位。**判断**：成片品质是跨风格通用的版式纪律，
不是风格并集。**迁移**：大数字自带参照系（孤立大数字是海报不是数据）；对比页只染答案；
时间轴以时期命名。**教训**：学样本不学皮——拆判断，不拆色值与截图。

**案例 5 · 水墨气质的两种死法**：封面是世界本体水墨，收尾却出摄影感远山（器材级空气
透视、渐变霞光、对称构图）——图像模型默认分布是「数字喷枪 + 图库风景」，不把材质
语言写死进提示词它就选最廉价的。**修法**：出图层在选择水墨语言时自动注入工艺纪律与
反向清单。**教训**：审美决策（用不用水墨）留给导演；「选择水墨却允许画得廉价」是执行
质量事故，归工程——写进代码的是失效模式，不是口味。

**案例 6 · 阅读器会沉默失败**：meta 行尾部字形缺失，PPTX XML 完整、PowerPoint 正常
——某阅读器在「字符间距 ∧ run 级透明度并存」时丢弃 run 尾部字形；60dpi 缩略图还把
截断误读成对比度不足，险些改错方向。**修法**：带字距的文本不用 run 级透明度；meta 行
`wrap=False` + 盒宽冗余；目检裁决用 150dpi 裁切。**教训**：交付品质 = 设计判断 ×
阅读器事实；后者住契约与 DNA。

**短案例（同一类错误的四种面孔）**：

| 症状 | 判断 | 修法 | 教训 |
|---|---|---|---|
| 5 张同面积卡片，机器全绿但层级失手 | 不敢决定哪个结论最重要 | 主结论提到 64 独占上半幅，其余降为无容器纯文本，删描边底色 | 先有「这页只有一句话」，卡片才会自己消失 |
| 两页堆叠柱，一页 12 期占比一页 4 季度绝对值（`DATA_INTEGRITY_FAIL`） | 诚信问题不是样式问题 | 统一 basis，绝对值挪附录，两页 unit/period 同写 | 图表一致性首先发生在数据语义层 |
| 开场页一句话占 6%，像没做完 | 空档是主角：让它有名字并兑现 | 写明空的职责，文字落左上 1/3 交点，1px 细线拉开与来源区的光学关系 | 「看起来空」和「空得没道理」是两件事 |
| 多条节奏/风险提示，作者顺手改色/字阶/圆角，另一页被切断 | 留痕信号不要求被消掉 | 只修唯一 error 根因，其余留在 trace | 「为了提示」改设计＝被刻度牵着走 |

## 2.5 正面走查（四问怎么答才算答了）

症状案例教人避坑；走查教人出发。以下三条走完 claim → form（含否决了什么）→ space，
全程只动判断，不动坐标与色值——同样的四问换一副 deck 会得出完全不同的版面，
这正是「相同内容不默认产生相同布局」的本意。

**走查 A · KPI 主张页**（标题带唯一数字）
**claim**：本页唯一结论是「自有内容占比已过半」，不是「这里有几个指标」。
**form**：数字该多大？先问观众三秒后记什么——记比例，不是记卡片。否决了四卡阵列
（四件事平权 = 没有结论）、否决了环形图（占比只有一个值得说的份额时，圆环是把
一句话画成一圈）；落成单一 KPI 大数字 + 参照系小字（对比基期），唯一染色只给答案。
**space**：大数字周围的空白不是浪费，是参照系——把结论从页面噪音里隔离出来；
说不出职责的留白才会显得「没做完」。

**走查 B · 风险页**（deck 级 tension 的正面落点）
**claim**：直面观众最大疑虑（「去年同类项目失败了」），本页回答「这次为什么不会」。
**form**：风险是主张不是数据——否决了雷达图/评分表（伪精确只会显得心虚），落成
三条「疑虑 → 这次不同」的对照行，每行后件必须是可验证的动作或机制，不是形容词。
**space**：疑虑与回应之间留一口气（分段），让「被听见了」先于「被说服」发生；
三行挤成一团 = 防御姿态，阅读节奏出卖了内容姿态。

**走查 C · 收尾页**（把疑虑了结，把决定交回）
**claim**：收尾页唯一任务是让观众能向别人复述决定——一句话主张 + 下一步。
**form**：否决了总结卡片墙（观众不会在最后一页重新读完八页内容）、否决了致谢页
（情绪代替不了决定）；落成宣言式大字主张 + 一行可执行 next step。
**space**：全幅重置，本页密度全 deck 最低——沉默在这里是权威感本身；
最后一眼的安静，就是交回决定时的笃定。
