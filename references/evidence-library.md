# Evidence Library

## 使用协议

参考证据不是风格命令，也不是品牌复制。每张 Evidence Card 必须完成四步：**观察行为 → 提炼原则 → 写成执行规则 → 明确反例与边界**。引用时记录来源、访问日期、证据强度和适用场景。若只有审美印象而没有可观察行为，则不能进入设计决策。

## 编辑设计微距库（Micro Rules）

> 上一节 5 张 Evidence Cards 是「方向级」证据（指路）；本节是「微距级」知识（可执行）。
> 它们**不是 guard 的确定性规则**——guard 仍只管硬约束，本节供 LLM 在生成 spec 与
> 做审美判断时参考。每条 = 一个具体动作 + 一句话原理 + 边界（触发条件内嵌于字号段、
> 页面型与色彩行为描述中）。照做能稳定提升「高级感」，但不是法律：内容与受众优先。
>
> **使用协议（三步）**：① 确认触发条件（本页是否落在该条的字号段/页面型/色彩行为内）；
> ② 适用即执行；③ **冲突仲裁**——同类冲突（如行高 5 vs 行长 6）按「可读性 > 阅读带宽 >
> 精致感」取舍；跨类冲突直接听 `design-intelligence.md` 的 Design Judgment
> （事实 > 可读性 > 内容任务 > 情绪 > 品牌）。不仲裁就执行两条冲突规则，是规则执行的
> 特征，不是设计判断。

### 一、排版微距

1. **中西混排间隙**：CJK 与拉丁/数字之间留 1/8–1/4 em（细空格）。中文与数字紧贴是中文 PPT 的头号廉价感来源。
2. **Display 负字距**：42px 以上大标题，拉丁字母收紧 -1%–-2% 字距；CJK 大标题不加字距（方块字本身密）。
3. **Caption 正字距**：11–13px 的眉标/来源/页码，拉丁加 +0.4–1.2pt 字距，营造「被刻出来的」精致感。
4. **大数字收紧**：KPI 数字（52–80px）收紧字距，避免「1,234」松垮；但**不缩小字号**——缩字号≠变精致。
5. **标题行高 1.05–1.15**：两行标题贴紧，成一个视觉块；正文行高 1.3–1.5，给阅读呼吸。
6. **行长**：CJK 每行 22–38 字、拉丁 45–75 字符是最佳阅读带宽；超了拆句或收窄版心，绝不缩字号。
7. **一页一焦点**：只有一个元素能拿到页内最大字号（≥1.25× 第二大字）；其余都是「陪衬」，不是「并列」。
8. **标题写洞察**：标题 = 对象 + 变化/差异 + 含义，可脱离页面独立复述；「市场分析」这类字段名标题，等于没有标题。
9. **光学对齐**（无法用代码强制的部分）：大写拉丁与 CJK 同行时视觉偏低 1–2px，可微调 baseline；数字在圆角容器里应略高于数学中心；混排共 baseline 而非顶对齐。
10. **数字等宽**：表格/排行榜里的数字用 tabular figures（等宽数字），小数右对齐，否则一行数字对不齐一眼廉价。

### 二、留白与构图微距

11. **大留白 ≥40%**：opening / closing / insight 页，留白本身就是「仪式感」，不是「没填满」。
12. **标准留白 25–35%**：context / solution / proof 页，阅读舒适区。
13. **紧致留白 15–25%**：evidence 数据页，密度高但**不拥挤**（拥挤 = 元素间小于 24px）。
14. **相邻页留白型不重复**：同一留白职责（protect_focus / create_authority / separate_chapter / hold_emotion）不连续 3 页。
15. **图文比例**：含 Hero 图页，图宽与标题栏宽取 1.618 / 1 / 0.618 之一，不做「图占半页 + 文字占半页」的对称切割。
16. **焦点落轴**：主焦点中心落在中线 / 三分线 / 黄金分割线上（±4.5%），是「被决定的位置」而非「排版余数」。
17. **来源固定左下**：页码/来源永远同一象限同一位置，跨页基线不漂移。
18. **重力锚点**：每页声明 `gravity_anchor`，先定重心再摆元素，而非「把元素放完看剩什么」。

### 三、色彩微距

19. **Accent ≤5% 面积**：强调色稀缺才有「强调」；超过 5% 就退化成「另一个主色」。
20. **中性色带冷暖**：纯灰 #808080 显廉价；暖灰（纸/米）+ 冷灰（轨道/线）交替，中性格调才有材质。
21. **同色相明度阶梯**：表达层级用同一色相的明度差（L 差 ≥1.5 JND），不用新色相填层级。
22. **单一信号色**：一套 deck 一个信号色（accent），其余全是中性 + 信号色的明度变体；多色相 = 没重点。
23. **强调角距离 ≥12°**：accent 与 primary/secondary 色相差小于 12° 时，强调色只是主色的重复，拿不到唯一重点。
24. **中档色在感知空间插值**：tint/shade 用 OKLab（或至少 OKLCH）而非 sRGB 线性，否则中档色偏灰偏浊（脏色）。
25. **渐变是留白手法**：同族低对比渐变（#F8F5EF→#EBE5D9）是呼吸；互补且等彩度的渐变会「混出脏灰」，禁用。
26. **深底浅字 / 浅底深字**：文字对比实测 ≥4.5:1（正文）、≥3:1（注记），低于就是「深底深字」的叠加不可读。

### 四、图表微距

27. **直接标注优先于图例**：数据点旁直接写数值，读者不用「看图例—找颜色—回图」；直接标注够用时关掉重复图例与坐标读数。
28. **一个强调点**：一张图只高亮一个数据点/一条序列（accent），其余同色系低饱和。
29. **环心 KPI**：donut 的洞放「总数/结论」，洞不是装饰，是「这一图到底说了什么」的单一读数。
30. **small multiples**：一页多组趋势用去轴迷你图（sparkline）同框对比，形状对比 > 数字罗列。
31. **参考线承载叙事**：目标线 / 基准线带标签，让「现在在哪 vs 要到哪」一眼可读。
32. **瀑布桥接**：瀑布图段间用虚线连接、小计段 accent 着色，表达「明细→小计」的桥接结构。
33. **最多 8 类别、3 语义色**：超过就拆图或改表格，不压缩字体、不堆色。
34. **零轴诚实**：条形/折线从真实数据域起，不截断制造「视觉夸大」；瀑布零轴按数据域映射。
35. **数据墨水比**：删掉一切不承载信息的网格线、边框、装饰；留下的每根线都要解释「为什么在」。

## 证据治理

Evidence Card 只影响 Direction 和 Critic 的判断，不得覆盖事实、可读性、可编辑性和项目品牌规则。多个参考发生冲突时，优先受众与内容任务，再优先证据强度，最后才是审美偏好。对外部案例的描述应保持克制，不把未经验证的“行业共识”写成事实。

仓库内预置的 Evidence Card 是打包期固化的基线证据，未随包记录 `accessed` 与 `confidence`。每次实际引用前必须：按记录模板补记当前访问日期、复核来源链接仍然有效，并依据复核结果给出 `confidence`；链接失效或无法复核时降为 `confidence: low`，只可用作方向启发，不得作为硬性设计规则的依据。
