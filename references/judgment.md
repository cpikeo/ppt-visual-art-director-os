# Judgment（设计判断校准 · 即时读取）

回答「这一页为什么应该这样呈现」。数值与字段契约 → `contract.md`；资产链 → `assets.md`。

## 1. 判断顺序

```
内容理解 → 受众 → 决策 → 结论 → 信息权重 → 视觉角色 → 焦点 → 构图 → 空间 → 媒体 → 规格
                                                              ↓
                                              跨页校准（看完全套后回拨单页）
```

- **受众 / 决策**：谁在看、看完要做什么决定。这两个答案压过后面的每一条推导。
- **结论**：本页唯一可复述的一句话。不是标题话题、不是字段名。写不出结论的页先重写或删除。
- **信息权重**：必须最大化 / 必须弱化 / 必须删除——三档都要能说出理由。
- **视觉角色**：establish（建立）/ explain（解释）/ compare（对比）/ prove（证明）/
  persuade（说服）/ summarize（收束）。角色不同，页面的义务不同。
- **焦点**：3 秒内的唯一主语，必须承担结论；**能解释为什么不是别的元素**。
- **构图**：大留白 / 编辑排版 / 数据场 / 图片叙事 / 线性结构 / 非对称张力。
  选它的理由与被否掉的五种理由同等重要。
- **空间**：阅读路径、主区、安静区、四层权重（背景 / 结构 / 内容 / 焦点）、留白职责。
- **媒体**：没有这张图，这一页会下降在哪里？只有「它是证词」或「它就是主语」两种答案成立。

## 2. 反模板

**不要从页面类型推导页面长相。** Statement 不等于必须大字，Data 不等于必须图表，
Case 不等于必须摄影，Framework 不等于必须卡片。**相同内容不默认产生相同布局**：
同类内容在不同受众、不同证据形态下可以长得完全不同——这正是判断存在的地方。

判据不是「每页看起来相同」，而是「把任何一页换进别的 deck 会立刻显得不属于」。

## 3. 减法链

```
删除 > 重组 > 排版 > 强化 > 装饰
```

「高级感不足」默认先怀疑判断不足，而不是元素不足。这句能不能删？两块能不能并？
层级能不能只靠字号与墨色拉开？都试过才轮到强化与装饰。
**「所有东西都设计得很明显」是最典型的失手**——常常是没有任何东西愿意安静下来。

## 4. 焦点与构图

- 一个主语，一个锚点。最大 ≠ 最该被看见：先确认它真的承担结论。
- 读白是承重结构：说出它保护了什么。有职责的留白常常是最贵的设计。
- 构图算子优先于原型：轴线（居中/偏置/不对称）、不等分割、尺度对偶、叠压、动线、负空间。
- **算子由内容的形状选，不由页面类型选**：几个数字共享基线 → 数据场；只有一个数字要立住 → 大留白；
  箭头/阶段链 → 线性结构；两方不对等 → 非对称张力；长文与论据段 → 编辑排版；
  图像通过必要性测试 → 图片叙事。六个算子在候选里打分，没选中的要以这一页的事实说明为什么落选。
- 卡片三准入：需要物理容器语义 / 需要与复杂背景隔离 / 需要被指认为独立对象。
  三条都不成立就退回「场 / 线 / 型」。等面积等权重的卡片墙通常意味着没有做出选择。

## 5. 排版与色彩

- 字阶建立阅读路径：相邻级差足够，每页层级克制；**粗体每页至多一处**，粗体词必须承担结论。
- 被引用的句子要大到可被引用；meta 行永远单行。
- 颜色是关系性的：基础色建立场域，信息色承载文字与数据，支持色负责区分，
  强调色指向**一个**语义目标（答案 / 当前 / 风险 / 印章），永不铺面。
- 低饱和不天然等于高级：米色 / 黑白灰 / 暗色 / serif / 大留白 / 金色 / 圆角 / 阴影都不自动产生高级感；
  它来自比例、节奏、视觉重量、留白职责、色彩关系、材质真实与叙事一致。
- 每个元素都要能回答「为什么存在」；答不出的先删，再谈强化与装饰。
- 色觉冗余：色相不是唯一区分维度，红绿并置时必须另有明度或位置的冗余。

## 6. 图像

一张图必须回答三个问题：

1. 它建立**空间**，还是表达**对象**？
2. 它证明了哪一句话，或让观众感受到哪一句话？
3. 它的光线、材质与负空间属于这套视觉世界吗？

唯一的理由若是「看起来高级」，删除。出图前逐张自问：光是一句话吗（均匀的光 = 塑料）？
空间有空气吗？材质是真的吗（过锐化与 HDR 感是「假」在补偿的指纹）？负空间在呼吸吗？
主体成立吗？它属于这个世界吗（一张异世界的图毁掉整稿世界观）？

## 7. 数据与证据

- 一图一关系；一个统一口径与一个时间区间；长度编码共享同一基线。
- 空间允许时直接标注，而不是图例；强调只指向一个答案。
- 只有在参照框架存在时，一个大数字才成立；孤立的大数字是海报不是数据。
- 数字无法比较、无法放回语境、无法指导行动时：先修数字或删页面，不是修图表。

## 8. 节奏与整套

Deck 通过对比呼吸：图像与原生证据、深色与浅色、疏与密。**只有当内容、情绪或叙事真的
变化时才改变页面**。章节过渡页是重置不是内容；结尾页回收封面语言，不放谢谢页。

跨页校准（单页判断做完后看整套）：连续 ≥3 页同构图时回拨中间页——但只在内容允许
第二选择时换，内容强烈要求同一构图就不换（内容契合压过节奏）；焦点连续 ≥4 页
同落点时提醒作者确认，不硬改焦点；图位超额时落选页直接改写为不要图。
校准只收敛节奏，不发明新布局、不改变任何一页的结论与角色。

三个尺度复核：**缩略图尺度**（整副是否有节奏）、**三秒尺度**（每页是否迅速建立主题）、
**三十秒尺度**（受众能否解释主张、证明与下一步）。

## 9. 停止

```
沟通清楚 · 焦点单一 · 三秒能读出层级 · 构图有明确意图
每个资产都有存在理由 · 数字诚实 · 重要内容没有被隐藏 · 没有值得继续删除的东西
```

验证是停止信号，不是继续抛光的邀请。最后一轮编辑是减法：删掉一个元素而意义不变，就该删掉它。
