# Judgment（设计判断 · 即时读取核心）

回答「这一页为什么应该这样呈现」。不是布局表、色板库或页面模板。
数值契约 → `contract.md`；资产链 → `assets.md`；案例与 DNA → `precedent.md`。

## 0. 唯一决策链

每页只走一次这条链：

```
Audience → Decision → Claim → Tension → Focus → Form → Space → Media → Spec
```

- **Audience**：谁在看，看完之后应该更容易做出什么决定？
- **Decision**：整副 deck 要支持的那个唯一决定（动词 + 对象）。
- **Claim**：本页唯一结论——受众能复述的一句话，不是主题标签。证据等级不足的页面
  不配大号 KPI、强 Accent 或英雄图。
- **Tension**：观众当前的疑问 / 风险 / 阻力。页面要么回答它，要么承认它。
- **Focus**：视线第一落点。它必须承载本页结论，而不是装饰、页码或眉标。
- **Form**：让洞察可见的最低戏剧化表达。先问：需要图吗？需要图表吗？需要卡片吗？
  相同内容**不默认产生相同布局**——同一种洞察可以大尺度呈现，也可以极致克制、
  用空间关系或数据证据呈现。
- **Space**：留白承担什么——保护焦点 / 承载情绪 / 制造权威感 / 分隔章节。
  说不出职责的大片空白是排版事故；有职责的留白常常是最贵的设计。
- **Media**：需要资产吗 → 它是空间还是对象 → 它为什么存在 → 画面究竟出现什么
  （四步详见 `assets.md`）。数据/结构/流程/对比页的注意力属于内容本身，出图 = 双焦点竞争。
- **Spec**：以上判断落成元素。标题写结论不写字段名；先删，再写。

当一页无法说清自己的 Claim 与 Focus 时，它还没有准备好进入坐标与元素阶段——
先重写或删除这一页，再添加元素。

## 1. 反模板原则

**不要从页面类型推导页面长相。** 因为它是 Statement 不等于必须大字、Data 不等于
必须图表、Case 不等于必须摄影、Framework 不等于必须卡片。家族（family）只辅助路由
（锚点词汇 / 媒体闸门 / 形态问题校准），不是内容的默认答案；密度（density）由成稿
测量或作者声明，不由标题词预定。**先判断内容为什么值得被这样看见，再决定视觉形式。**

**相同内容不能默认产生相同布局。** 引擎不给「家族 → 构图语法」的先验答案；
规划产出的是判断问题，答案由这一页的内容决定。

## 2. 减法链（核心操作系统）

「高级感不足」默认先怀疑判断不足，而不是元素不足。唯一修法顺序：

> **删除 > 重组 > 排版 > 强化 > 装饰**（删 → 合 → 排 → 强 → 装）

这句能不能删？两块能不能并？层级能不能只靠字号与墨色拉开？都试过才轮到强化装饰。
能用空间关系解决的，不要用新元素解决。高级感来自**更少、更准确、更有秩序的决定**。

**「所有东西都设计得很明显」是最典型的失手**——常常是没有任何东西愿意安静下来。
说不出职责的色块 / 线条 / 对齐 / 图标都是噪音。看到症状（模板感 / Dashboard 感 /
卡片墙 / 组件堆叠 / 过度圆角阴影渐变 / 无意义图标线条 / 为高级而高级 / 每页同结构），
先问「哪个判断缺席了」，再沿链从左修。故意做出某项，只要在 `composition_grammar`
写清意图就成立。

## 3. 五个导演级判断（发布前逐页过一遍 · 无分数 · 无权重）

**Focus —— 一个主语，一个锚点**：3 秒内是否只有一个主角？「大标题 + 三张同面积卡片 +
一个图表」同场时读者会跳过整页——主语之外的元素都要能被降级，**降级幅度不够 = 没降级**。
「最大」不等于「最该被看见」：先确认它真是主语。

**Composition —— 留白是承重结构**：元素落在轴线上还是随手居中？空白有名字才有价值。
每页能点出四层：Primary Focus / Secondary / Supporting / Negative Space。非对称允许，
但要说出靠什么平衡（尺度 / 墨色 / 材质 / 留白之一）。

**Reading —— 路径、对比、诚信**：视线顺序由尺度 / 明度 / 位置决定；「哪儿都能开始看」
等于没有叙事。**数据表达不许撒谎也不许藏**：双轴、非零基线、堆叠占比、口径不齐先是
诚信问题；读者要自己心算才能确认结论＝图画错了；估算与外推必须带标记（EST./E）。

**Expression —— 气质、材质、色彩人格**：页气质是否匹配内容语气？**高级感不是一种色板**
——降饱和 / 米色 / 黑白灰 / 莫兰迪都不自动等于高级；高级来自关系准确：每色有职责、
色相族克制、强调稀缺、对比可读。方向混搭一次只混一个维度。

**Continuity —— 整套 deck 是一个作品**：节奏 / 母题一致性 / 至少一个可复述记忆点都在
deck 级才存在。**统一与差异都是手段，正确才是目的**：说不出理由的变化是空转，
说不出理由的重复是复制。

**两条贯穿纪律**：修正是设计动作不是分数动作——一轮只修一个根因。审美标尺用来校准
判断不是用来复制——参考 Apple Keynote / Pentagram / FT / Kinfolk 是学「为什么把那个
数字放那么大」「为什么敢留那么多白」；版式截图、色板、组件一律不带走。

## 4. 构图（算子优先于原型）

先组合算子，再看落哪个原型附近：

- **轴线**：居中、偏置或不对称；
- **切分**：不等分优先，等分只用于同坐标系对比；
- **尺度对偶**：一个巨大的结论对应小尺度的证明；
- **叠压**：只有当深度或关系改变意义时才使用；
- **动线**：水平表达顺序，垂直表达权威，对角表达张力；
- **负空间**：明确它的职责（见 §0 Space）。

阅读顺序是一种空间论证。第一落点必须承载页面主意义，不能落在装饰性照片边缘、
页码或强调线上。分组成本递增：**场域（48px+ 间距）> 对齐 > 发丝线 > 字体层级 > 容器**。
卡片三准入：需物理容器语义（数据模块/KPI）、需与复杂背景隔离、需被指认为独立对象；
三条都不成立退回场/线/型。等面积、等权重的卡片墙，通常意味着没有做出选择。

**构图判断三问**：视觉中心在哪？第一眼看到什么？删除任一元素表达是否改变
（两者皆可删则皆应删）。

## 5. 字体与色彩

字体通过字号、字重、位置、行高、宽度、字距与静默建立阅读路径。粗体词必须承担一个
结论；如果每个标签都是粗体，就没有任何标签真正被强调。**粗体每页至多一处**，
不够先动位置与留白。meta 行永远单行。

色彩是关系性的：基础色建立场域；信息色承载文字与数据；支持色负责区分但不争夺注意力；
强调色指向一个语义目标（指认答案 / 当前 / 印章 / 主题）；负面色不是第二强调色。
低饱和不天然等于高级——每个元素都在索取注意力的浅色 deck 照样廉价。
语义色常落红绿：色相不是唯一区分维度，红绿色弱观众不少——红绿并置时必须保证
明度差一档以上，或加位置/直接标注冗余，否则「涨跌」在投屏上对一部分观众不存在。
字阶驻点、对比底线等数值 → `contract.md`。

## 6. 图像判断

一张图必须回答三个问题：

1. 它是在建立一个**空间**，还是在表达一个**对象**？
2. 它证明了哪一句话，或让受众感受到哪一句话？
3. 它的光线、材质与负空间是否属于这套视觉世界？

如果它唯一的理由只是「看起来高级」，就删除它。出图前逐张自问：
**光是一句话吗**（均匀的光 = 塑料）？**空间有空气吗**？**材质是真吗**（过锐化与
HDR 感是「假」在补偿的指纹）？**负空间在呼吸吗**？**主体成立吗**？**它在这个世界吗**
（一张异世界的图毁掉整稿世界观）？廉价症状（图库式居中主体、四角重暗角、塑料反光、
过饱和、AI 素材感）命中即重出——负面清单已由代码在出图层拦截。

## 7. 数据与证据

图表是视觉论证，不是自动套用的组件。一图一关系；一个统一口径与一个时间区间；
空间允许时直接标注而不是图例；长度编码共享同一基线；高亮只指向一个答案；
来源、单位与假设保持可见。

只有在参照框架存在时，一个巨大的数字才成立。孤立大数字是海报不是数据。
如果数字无法比较、无法被放回语境或无法指导行动，先修数字或删页面，不是修图表。

## 8. 节奏与整套（deck 级）

Deck 通过对比呼吸：图像与原生证据、深色与浅色、疏与密。只有当内容、情绪或叙事
发生变化时才改变页面；强行制造变化与重复模板一样机械。章节过渡页是重置不是内容
——全幅视觉 + 单 statement、密度归零；结尾页回收封面语言，不放谢谢页。
跨页连续性双锚：眉标固定上缘、页码固定象限，锚不动正文才可游走。

**同一视觉世界**：统一的是世界，不是页面——同一材质与光的逻辑、排版声音、锚点词汇、
图表性格、色彩纪律；在此之内每页可自由换构图、密度、色重与标题位置。判据是
「把任何一页换进别的 deck 会立刻显得不属于」，而不是「每页看起来相同」。

用三个尺度复核：**缩略图尺度**（整副 deck 是否有节奏）、**三秒尺度**（每页是否迅速
建立主题）、**三十秒尺度**（受众能否解释主张、证明与下一步行动）。

## 9. 取舍优先级与停止

低层永不为高层让位：

```
信息关系 > 空间秩序 > 排版 > 视觉表达 > 装饰
事实与语义 > 可读性 > 内容任务 > 情绪 > 品牌 > 通用审美
```

打破规则的两个判据：它是主动决定（能一句话说清为什么，且新重心更明确），
且一次只打破一条。场合先于品味：内部周报不必有记忆锚点，发布会不该塞满表格。

满足以下条件时停止：

```
沟通清楚 · 焦点单一 · 三秒内能读出层级 · 构图有明确意图
每个资产都有存在理由 · 数字诚实 · 重要内容没有被隐藏 · 没有值得继续删除的东西
```

验证是停止信号，不是继续抛光的邀请。最后一轮编辑是减法：删除一个元素并没有减少
意义，就删除它。
