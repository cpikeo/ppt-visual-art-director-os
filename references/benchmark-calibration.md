# 基准校准方法论（Benchmark Calibration）

> 本文档回答一个问题：如何把 Art Critic 从「规则化的品味」校准到「真实好作品的品味」。
> 方法论的执行工具已就位：`scripts/calibrate.py` **只测量、只建议、只记录，不碰任何常量**
> （改动由人复核后手工落库并留校准记录）。仓库内不放置标注样本（避免污染自测），
> 样本集与 labels 放仓库外的私有基准目录。

## 工具（calibrate.py）

```bash
# 第一步：从 build module 生成标注模板（人工只填 score 与 why）
python3 scripts/calibrate.py --init path/to/build_module.py --labels labels.json

# 第二步：标注完成后跑分析（复用 <pptx>_render/ 证据目录，缓存命中即免渲染）
python3 scripts/calibrate.py --labels labels.json --build path/to/build_module.py \
       --pptx path/to/output.pptx --report calibration_report
```

labels.json：`{"labeled_by", "date", "pages": [{"slide", "score"(0–5), "why"}]}`。
工具产出：Pearson(critic 页分, 人工分)、错杀率/漏放率、逐特征阈值反推（好/差最佳分界 + 当前默认对照）、改动记录模板。**样本守门**：匹配 <6 页或好/差任一桶 <2 页时拒绝给出任何建议——样本不足时的「校准值」是噪声拟合。

## 0. 为什么这是唯一能提审美上限的事

Art Critic 现在有 9 个维度、几十条启发式，阈值（见下）全部是**经验默认值**，从未被真实
好作品反推过。这带来两个后果：

1. **上限被封死**：分数反映的是「与这套默认规则的吻合度」，不是「与人类审美判断的吻合度」。
   规则再对，也追不上训练有素的眼。
2. **Goodhart 风险**：Agent 学会「刷 rubric」（把焦点拉到 40px、硬贴三分线拿加分），
   分数涨、设计平庸。

校准做两件事：用人工标注反推阈值（让规则逼近好作品），并把「Critic 分数 vs 人类分数」
的相关性变成 Critic 的新 KPI（让刷分 = 逼近好作品，无害化）。

## 1. 标注什么

**样本**：30 页渲染成品（不是 spec，是最终 PNG），覆盖你真实要做的场景——封面 5、数据 8、
对比 5、结论 4、框架 4、章节/案例 4。好 : 中 : 差 ≈ 1 : 1 : 1。

**评分**：每页打一个 0–5 的整体审美分（不是 9 维分开打，整体分更接近真实观感），加一句
「为什么」（一句即可，用于反推阈值时定性判断）。

**锚定**（关键，否则主观分不可比）：
- 5 分 = 你会直接放进给董事会/客户看的成品，不改。
- 3 分 = 可用，但你会改两处以上。
- 1 分 = 你不会用，重做比改快。
- 2、4 分 = 介于其间的过渡。

**不要做的**：不要给「守了多少条规则」打分——那是在给旧阈值背书，校准就白做了。只问
「这一页好不好」。

## 2. 反推阈值（拿到数据后怎么做）

对每个阈值，做法相同：**找那个能把「好（≥4）」和「差（≤2）」分得最开的临界值**。

| 阈值 | 位置 | 当前默认 | 校准目标 |
|---|---|---|---|
| `ANCHOR_DRIFT`（重心漂移） | art_critic.py | 0.18 | 好页的 drift 分布上分位，而非「0.18 看起来合理」 |
| `gravity_drift`（渲染漂移） | qa.py thresholds | 0.28 | 同上，用渲染实测值 |
| `accent_pixel`（Accent 上限） | qa.py thresholds | 0.08 | 好页 accent 占比的 90 分位 |
| `STATEMENT_SIZE`（Statement 锚点） | art_critic.py | 40 | 好页里「记忆点字号」的下分位 |
| `FOCUS_LEAD`（焦点领先） | art_critic.py | 1.25 | 好页焦点/次大字号的分布 |
| `LR_SPLIT_MAX`（左右失衡） | art_critic.py | 0.45 | 好页（未声明非对称时）失衡度上分位 |
| `accent 色距 0.30`（强调色检测） | render_check.py | 0.30 | 好页 accent 像素的实际色距分布 |

方法：对每个阈值，画「阈值值 vs 好/差区分度（准确率）」的曲线，取区分度拐点。**不追求
完美分离**（审美本就有噪声），追求「明显好于默认值」。

**不校准的**：`TEXT_CONTRAST_FAIL=3.0` / `TEXT_CONTRAST_WARN=4.5`、行长 38/75、负值禁令、
数据完整性——这些是**可读性与诚实性底线**，有客观标准（WCAG、阅读带宽），不是审美偏好，
校准反而会「为了好看放松底线」。底线只升不降。

## 3. 验证：把相关性变成 KPI

校准后跑一轮全量，算两个数：

- **Pearson(Critic 分数, 人类分数)**：目标 ≥ 0.75（当前大概率在 0.5–0.6）。
- **错杀率 / 漏放率**：好页被判 REVISE、差页被判 PASS 的比例，目标双双 < 15%。

这两个数写进每次校准的产出，作为 Critic 的**审美相关性 KPI**——它比「自测 29 项全 PASS」
更能说明「这个评分器到底有没有审美」。若相关性不升反降，说明阈值改动方向错了，回退。

## 4. 校准节奏（避免过度）

- **一年 1–2 次**，每次 20–30 页新样本。不是持续工程，是定期体检。
- **阈值改动必须可回退**：每次校准只动 1–3 个阈值，记录「改了什么、相关性从 X 到 Y」。
- **永不为了「分数好看」改 PASS_SCORE=90**：发布门槛是业务决定，不是审美校准对象。

## 5. 一句话总结

> 审美判断的载体，是「被真实好作品校准过的阈值」+「一个读得懂 SKILL.md 的好模型」，
> 而不是 art_critic.py 里再多一个维度。校准就是让前者追上后者。
